# BODY_GRAMMAR_CONTRACT_TESTS_V1

These tests are implementation-independent acceptance contracts.

## Semantics

1. Every rendered visual channel must resolve to a registered semantic meaning.
2. Measured, derived, reported and inferred visual elements must remain distinguishable.
3. No good/bad organ coloration is permitted.
4. Active warm accent requires an active finding reference.
5. Missingness may not render as zero or as healthy default state.

## Motion

6. If respiration source data are absent, respiratory body motion is absent.
7. If resting-HR / eligible pulse data are absent, pulse animation is absent.
8. A source-discontinuity state blocks affected physiological animations.
9. Decorative ambient motion is forbidden.

## Time

10. Historical scrub uses actual validity ranges.
11. Missing intervals remain visibly missing.
12. No hidden interpolation is permitted.

## Evidence

13. Inferred overlays cannot visually dominate measured overlays.
14. Low-evidence channels must remain visually less definite than high-evidence channels.
15. Clicking an active finding indicator must open traceable supporting evidence.

## Anti-hypochondria

16. A normal well-covered day may contain no warning beacon.
17. No-action states must remain visually intentional and complete.
18. The system must not use visual escalation merely to increase engagement.

## Accessibility

19. Provenance/evidence meaning cannot depend on color alone.
20. Motion-reduced mode must preserve all information via static equivalents.
