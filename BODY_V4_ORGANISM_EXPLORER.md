# HealthOS Body V4 — Organism Explorer

## Product objective

Body is no longer an illustration surrounded by cards. It is the main navigation mechanism for longitudinal physiology.

The user should be able to move through five operations:

1. organism → system
2. system → signals
3. present → history
4. observation → provenance/evidence
5. body → full longitudinal trend

## Visual modes

### State
Focuses the selected system while the rest of the organism recedes.

### Coverage
Makes observability itself the primary visual variable. Missingness remains visible and is never converted into zero.

### Provenance
Makes measured / derived / reported / inferred provenance visually explicit.

## Dossier

One contextual dossier replaces multiple generic cards. It has three tabs:

- Summary
- Signals
- Evidence

The dossier can open the primary longitudinal metric in Evolución.

## Time and comparison

The timeline supports 30d / 90d / 1y, explicit gaps, observed training events, latest-data jump, today jump, and a pinned comparison date.

Comparison is descriptive only. A delta is not interpreted as improvement or deterioration.

## Epistemic guardrails

- Motion requires measured evidence.
- Missingness is shown as fog/gap, never zero.
- Amber remains reserved for a traceable finding.
- Historical observations are not retroactively assigned current findings.
- Body does not publish a global body, resilience, or biological-age score.
- System selection changes navigation and evidence focus; it does not create diagnosis.
