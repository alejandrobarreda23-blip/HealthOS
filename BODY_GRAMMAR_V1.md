# BODY_GRAMMAR_V1 — Runtime implementation baseline

V1.16 turns the Body into a navigable physiological index.

Canonical visual rules:
- color testifies; it does not judge;
- motion requires eligible measured physiology;
- turbulence represents deviation, never moral value;
- the only warm accent indicates a traceable active finding;
- missingness is fog / attenuation / stillness, never zero;
- inferred information must remain less authoritative than measured information;
- every visual channel has a declarable semantic meaning.

The first runtime implementation is intentionally conservative: it uses existing Health Brief and Acquisition Intelligence only. It does not fabricate system scores, VO2max, respiratory rate, trends or anatomical localization that HealthOS does not actually have.
