# Personal Learning Loop V1.5

## Goal
Close the loop between behavior/event logging and longitudinal aging without pretending that association is causation.

## Pipeline
event
→ temporal exposure
→ matched association
→ personal evidence grade
→ outcome-to-system mapping
→ behavior/system impact
→ opportunity
→ optional scenario analysis
→ prospective N-of-1 experiment

## Personal evidence grades
- insufficient
- exploratory
- moderate
- strong
- experiment_supported

Sample size alone is not enough. Confidence, confounder coverage, replication and experiment status matter.

## Outcome → system mapping
An observed outcome may affect more than one system with different relevance.
Example: HRV primarily informs sleep/recovery here and secondarily cardiovascular physiology.

Relationships marked `range` or `contextual` are NOT assigned favorable direction by this layer.
They must first pass through the Risk & Reference Engine.

## Critical guardrail
Personal behavior evidence does not mutate the observed Health OS Pace.

It may:
1. explain possible drivers;
2. rank opportunities;
3. generate a sensitivity scenario;
4. propose a prospective experiment.

Only measured longitudinal system trajectories determine the observed Pace.

## Why this matters
If sauna is associated with improved HRV, Health OS may say:
“Sauna is associated with a favorable recovery signal in your data.”

It may not silently add points to the user's aging score.

If the user later increases sauna use and the measured recovery trajectory improves, that new measured trajectory can influence Pace through the normal pipeline.

This preserves:
OBSERVATION → ASSOCIATION → HYPOTHESIS → EXPERIMENT → CONCLUSION
